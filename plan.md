# Projektisuunnitelma Lapuan Lepakot

## Projektin tavoite
Projektin tavoitteena on luoda Lapuan Lepakot seuralle selkeät ja helppokäyttöiset verkkosivut.

## Kohderyhmä
Sivusto on tarkoitettu seuran jäsenille, uusille pelaajille sekä kaikille, jotka haluavat tietoa seurasta.

## Sivuston sisältö
Sivusto sisältää neljä sivua:

Etusivu: Seuran esittely ja tärkeimmät tiedot.
Tietoa seurasta: Lisätietoja seurasta ja sen toiminnasta.
Ottelut ja harjoitukset: Otteluiden ja harjoitusten tiedot.
Yhteystiedot: Yhteystiedot ja ilmoittautumismahdollisuus.

## Käytettävät teknologiat
HTML sivuston rakenteeseen.
CSS sivuston ulkoasuun.
JavaScript lomakkeiden toiminnallisuuteen.

## Ulkoasu
Sivuston väreinä käytetään syvää luumunviolettia, valkoista ja kultaista korostusväriä.

## Tavoite
Sivuston tulee olla helppokäyttöinen, selkeä ja toimiva sekä tietokoneella että mobiililaitteilla.
