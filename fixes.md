## korjauksia ja muutoksia
Tein muutoksia html rakenteisiin koska siellä koodissa oli kirjoitusvirhe.
Lisäsin CSS media query säännöt, joiden avulla navigaatio muuttuu pystysuuntaiseksi pienillä näytöillä.
Muutin navigaatiolinkkien värit niin, että ne näkyvät selkeästi myös tummassa tilassa.
Lisäsin CSS focus-visible-säännöt, jotka näyttävät kultaisen reunuksen valitun elementin ympärillä.
Lisäsin viestille hidden-luokan ja muutin JavaScriptiä niin, että viesti näytetään vasta lomakkeen lähettämisen jälkeen.
